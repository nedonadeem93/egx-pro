☁️ التشغيل على Streamlit Cloud (مجاني)
1️⃣ ارفع الكود على GitHub — اعمل repo وارفع ملفات المشروع (زي ما بنعمل دلوقتي) — الملفات دي آمنة، مفيش فيها أي توكن.

2️⃣ اعمل التطبيق — ادخل share.streamlit.io → سجّل دخول بحساب GitHub → Create app → اختار الـ repo (egx-pro) والفرع (main) → Main file path: egx_pro.py → دوس Deploy.

3️⃣ الصق التوكن في Secrets (أهم خطوة) — من تحت يمين التطبيق → Manage app → ⋮ → Settings → Secrets → الصق قسم [esthmr] بالقيم الحقيقية بالشكل ده:

[esthmr]client_id     = "..."refresh_token = "..."
دوس Save → التطبيق هيعمل restart أوتوماتيك.

4️⃣ خلاص 🎉 — التوكن بيتجدد لوحده، مش هتحتاج تسجل دخول أبداً. عدّاد الرصيد 🔋 هيظهر فوق، والبيانات الرسمية هتبان في التقريرات.
